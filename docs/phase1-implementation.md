# 第一阶段：无 AI 原生宠物原型

本阶段实现 macOS 原生透明角色窗口、单击抚摸与一次性短动作、拖动、菜单栏显示/隐藏/退出、100–220 pt 尺寸设置、跨屏位置恢复和休眠恢复。只制作并使用一个原创角色小样，其他姿态等待用户认可形象后再派生。

没有 OpenRouter 客户端、网络请求、system prompt 编辑、长期记忆、工作 Agent、亲密度计分或主动招呼调度。抚摸后的短文字是本地反馈，不是 AI 回复。位置和尺寸当前只在内存中保留，重启恢复默认；持久化留在第二阶段。

## 透明区域采用事件驱动命中

角色 PNG 的 alpha 在构建时导出为 512 × 512 的单字节 mask。显示时按图片位置和缩放判断鼠标是否落在角色本体，使用 `NSWindow.ignoresMouseEvents` 切换整个角色面板是否接收鼠标。Apple 明确定义该属性为窗口是否对鼠标事件透明。[1]

为了在窗口忽略鼠标时仍能发现指针进入角色，需要本地与全局的鼠标移动事件监听。只监听 `.mouseMoved`，只使用当前坐标，不监听按键、不记录鼠标历史、不读取屏幕内容或其他应用文件；隐藏、休眠和退出移除监听器，不设持续轮询计时器。Apple 文档说明两类监听的范围、回调运行在主线程，以及全局键盘事件的辅助功能条件；本应用没有请求键盘监听权限。[2]

拖动期间保持窗口接受鼠标，释放后恢复 alpha 判定。角色面板明确不能成为 key 或 main 窗口；设置窗口只有用户主动打开时才激活。全屏策略不使用 `fullScreenAuxiliary`；实际不同应用全屏与多显示器组合还需要用户的桌面体验验证，不能仅凭配置属性宣称已经端到端通过。

## 构建与验证

使用本机已有 Xcode 26.1.1、Swift 6.2.1、XcodeGen 2.46.0，无第三方运行时依赖。生成 `TuanTuan.xcodeproj`，Release 为 arm64、macOS 15+，本机 ad-hoc 签名；没有 Developer ID 公证，不作为对外分发版本。资源为 512 像素 PNG 与 alpha mask，不把 1920 像素原始小样加载进常驻进程。

几何、缩放和透明命中使用 XCTest；应用 `--validate-at` 入口验证自身 AppKit 状态并将自己的视图渲染到图片，不读取用户屏幕、不注入其他应用输入。内部检查不等于真人点击穿透、全屏切换或物理拔屏端到端测试。

资源测量使用外部 Python/ps 观察器，记录应用及子进程 CPU 时间差和 RSS，观察器不计入应用常驻进程。完整 30 分钟结果及局限记录在阶段交付说明中；尚未得到结果前不宣称达标。

## 本次已得到的验证结果

Release 构建成功，arm64 可执行文件的本机签名验证通过。最终应用在 macOS 15.6 上执行内部检查，16 项均通过；纯几何/alpha 用 SwiftPM 承载独立 XCTest，10 项全部通过、零失败。原图透明 alpha 为 0–254，四角全透明；最大 alpha 254 不构成没有透明背景，不为此重新生成角色。512 像素运行素材等比缩小，没有裁切角色。

最初尝试的 Xcode 图形宿主测试因本地测试执行环境限制没有完成，该次测试未记为通过；残留 Debug 宿主已按完整可执行路径核对并结束。`Package.swift` 提供纯逻辑测试，不改变原生应用运行结构；缓存、配置和安全目录定向项目 `.work/phase1`。应用窗口仍由 AppKit 内部验证覆盖，实际跨应用鼠标操作、全屏和物理多屏尚待用户体验验证。

本机当前只有一个在线 6016 × 3384 显示器，多屏逻辑已用虚拟几何用例验证，但没有实际拔屏测试。系统 WindowServer 快照只提供上下文，不能归因给团团；没有做 GPU 或系统能耗归因。资源观测在 2026-11-14 21:21 左右开始，完整结果未返回前不宣称达标。

## 0.1.1 分区互动更新

用户新增不同部位触摸反馈要求。新增 `PetTouchZone` / `PetTouchLayout` 四分区，先检查原图 alpha，再用相对坐标区分头顶、脸颊、肚子、尾巴；100–220 pt 下使用同一规则。按下保存触摸位置，拖动超过阈值后即便回到原处也不触发抚摸；放开在透明处也不触发。

原图由头、身、尾三个裁切图层共享同一个 CGImage。头顶动作只让头局部点头和轻弹；脸颊让头轻蹭并短暂显出脸红；肚子让身躯软弹并轻微带动头；尾巴只摆动尾部图层。没有持续帧回调、CoreImage 逐帧渲染、Live2D 或新生成姿态。短动画最长约 0.9 秒，重复触摸替换旧动画，隐藏、休眠或开始拖动时清理；结束回到静置。图层关节留少量重叠减少裂缝，但这是原型图片 rig，不是高精度骨骼或变形网格。

新版 Release 0.1.1 构建与本机签名检查成功。SwiftPM 独立 XCTest 16 项通过；AppKit 内部检查 33 项通过，包括四区 alpha 命中、独立反馈启动、气泡保持和动画清理。头、身、尾独立自绘视图确认部位没有上下颠倒或误把整张图作为一个局部层，静置合成保留原始形象。真实鼠标手感和动态边缘精确命中仍需要用户体验确认；当前热区以原图为基准。

静态 0.1.0 的 30 分钟观测已经完成：单核口径平均 CPU 0.2872%，采样峰值 2.0836%，RSS 峰值 19,218,432 字节，309 次采样，一个应用常驻进程，观测时长 1800.05 秒。该结果不等于新版分区动画通过同一测试。新版单独进行五分钟初测，完成后在交付说明中记录；五分钟不能外推为三十分钟验收。

新版五分钟初测实际结果：300.162 秒、59 次采样，平均单核 CPU 0.2432%，采样峰值 2.5636%，RSS 峰值 30,375,936 字节，一个应用进程；未超预算，但不宣称新版三十分钟验收已完成。采样不隔离用户活动，未测动画专项峰值、GPU 或系统能耗。完整口径和用户验收清单见 `outputs/phase1/Phase1-Delivery.md`。

时序回归先捕获到结束后动画条目残留：0.9 秒以内的动作在 1.1 秒后呈现层已回到静态姿态，speed 为 1、repeatCount 为 0、removedOnCompletion 为 true，但 AppKit 图层仍保留 animationKeys。不能仅凭该字段认定持续运动，也不能忽略残留状态。修复为触摸事件后安排一次可取消的一秒清理；新触摸和停止清理都会取消上一次回调，不用常驻轮询。临时状态探针已移除，保留动作呈现、自动清理、静态姿态与快速重复触摸的时序回归。

最终清理修复后：33 项 AppKit 检查与 21 项时序动画回归全部通过，纯逻辑仍为 16 项通过。最终构建独立五分钟复测为 300.114 秒、56 次采样，平均单核 CPU 0.1966%、采样峰值 4.1020%、RSS 峰值 34,537,472 字节、一个应用进程。交付说明使用最终构建数字；此前候选版初测作为历史记录保留。五分钟仍不等于新版三十分钟验收。
