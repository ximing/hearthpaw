# 0.1.2：原生设置与自定义 OpenRouter 模型

本轮根据用户要求完善设置，不提前实现聊天、二级路由、记忆或调研执行。原生设置窗口拆为外观/模型两页，模型 ID 手填，不内置易过期的厂商型号列表、不静默替换模型。模型保存只做格式校验，不证明模型存在、费用或工具兼容。

## 实现分工

`AppSettings.swift` 封装普通配置、格式校验和原子持久化。schema 只有 petSize、companionModelID、researchModelID。缺失返回默认值，损坏抛错，不静默覆盖；同目录独占创建 0600 临时文件，写入并同步后原子 rename，新建目录为 0700。写入失败清理暂存，保留旧配置。

`KeychainAPIKeyStore.swift` 只提供状态、保存、删除，当前没有读取用户密钥正文的接口。限定 generic-password、固定 service/account。个人本机 ad-hoc macOS 应用显式使用文件型登录钥匙串，并设置不可同步；没有明文回退、云端密钥服务或额外 access group。使用禁止交互的 LAContext，状态查询只请求属性不请求密码数据。用户钥匙串锁定或权限拒绝会报错，而不是弹出无人值守认证或换成 JSON 保存。

本机 SDK `Security.framework/Headers/SecItem.h` 对 `kSecUseDataProtectionKeychain` 与 `kSecAttrSynchronizable` 的说明是本次平台选择依据。经典 macOS 登录钥匙串不提供 iOS 风格 ThisDeviceOnly 可访问性标记，不能假装设置这个属性就生效。隔离检查确认实际拿到本地文件型 Keychain 项目引用，未据此承诺数据无法被用户手动备份/导出。未来正式签名或 App Store 版本若切换 Data Protection 钥匙串，需要单独设计签名、entitlements 与迁移，不能静默更换存储后端。

`SettingsWindowController.swift` 提供原生分段导航、secure 输入与独立保存、删除密钥；模型 ID 独立保存、复制、重读、恢复默认；尺寸在结束拖动时保存。普通设置损坏后禁用一般写入，仅用户明确确认恢复默认才可重建。模型草稿保留，尺寸同步不覆盖输入；关闭窗口清空未保存密钥。恢复模型默认不删除密钥。

AppDelegate 仅启动读取普通尺寸配置，设置页按需创建；不在启动时读取密钥内容或调用模型。设置页不新增常驻计时器、模型服务或浏览器进程。

## 验证与限制

30 项 XCTest 通过，涵盖原有几何/触摸、模型格式、原子保存重载、文件权限、损坏与失败保留、无密钥字段、密钥校验与脱敏错误。AppKit 验证使用项目内独立配置和 MemoryAPIKeyStore，绝不写生产配置或使用真实 key；覆盖保存重载、双模型独立、复制、草稿、恢复默认、损坏保护、secure 输入清空与自绘图。

系统 Keychain 隔离集成使用随机 QA service/account 与合成值，10 项通过：不存在查询、缺失删除、保存状态、新实例读回存在、仅对 QA 项核对值、非同步、本地文件后端引用、更新、删除和重复删除。测试结束删除 QA 项，不查询用户生产密钥。最初普通受限执行无法连接完整系统服务，正式验证在允许系统 Keychain 服务的执行环境完成；不把受限执行失败计为成功。

21 项原有动画时序回归继续通过。真实 OpenRouter 请求和用户自己的 key 尚未测试，也未产生模型调用费用。0.1.1 的性能样本不是 0.1.2 的完整性能验收；本轮未承诺新的三十分钟资源、GPU 或电池结论。原生自绘图不是跨应用真人鼠标端到端验收。
