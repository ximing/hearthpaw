# 宠物自主存在，AI 只响应显式文字对话

> 2026-11-14 第三轮后部分重新打开：用户明确提出陪伴 Agent 委派工作 Agent 执行真实任务。下文是第二轮接受的历史边界，不能把其中“仅文字辅助、不修改文件”继续当作整个新系统的最终规格。具体工作权限尚未确认；本地招呼不请求模型，以及不自动读屏、监听剪贴板或麦克风，仍未被用户撤回。

宠物的日常反馈、轻养成和主动招呼不依赖模型请求；只有用户主动提交文字对话时才调用 OpenRouter。用户接受主动招呼使用本地文案，并接受默认最多每小时一次、每天三次且可关闭或暂停，以换取可控费用、低常驻开销和不打扰；代价是主动招呼不根据屏幕内容或后台模型推理实时生成。

第二轮原范围：首版不自动读取屏幕、文件、剪贴板或麦克风，也不点击电脑、执行命令、发消息或修改用户文件。文字辅助针对用户主动提供的内容；请求可包含角色设定和约定的对话内容。跨会话记忆及其是否发送给模型当时尚未确认。

宠物保持无声，招呼不抢焦点。模型不可用时基本宠物行为仍应可用。第三轮进一步接受了聊天错误明确提示、保留输入、由用户手动重试，而非自动换模型或反复请求的建议。

## 新需求的影响

显式对话之后可能产生意图识别、路由和工作执行中的多次模型调用；原先“同一时间只一个聊天请求”的保护需要与工作任务并发重新协调。第四轮已确认索引/正文两层记忆、二级路由、按需工作 Agent 与首个调研报告任务，当前正式边界见 [ADR 0003](0003-companion-worker-indexed-memory.md)。这些决定仍不授权任意文件遍历或工具执行；原本地招呼、无声和不自动观察电脑等约束被新 ADR 明确保留。
