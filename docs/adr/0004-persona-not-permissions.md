# 可编辑人格，不让人格文本控制执行权限

用户可以自由编辑宠物身份、角色和语气的 system prompt，使用默认模板、保存、预览和恢复默认；首版修改同一只宠物，不做多角色档案库，改人格不自动清空亲密度或记忆。人格内容与应用固定的路由和执行规则组合，但工具权限、记忆访问范围及报告路径由程序校验，而不是靠 prompt 自律。

工作 Agent 使用独立的专业调研指令。宠物可以按用户设定的语气接任务、报进度与解释结果，报告本身默认认真、可核查；代价是人格文本不能任意改变工作 Agent 的行为和报告风格。网页及记忆正文属于资料，不可提升为操作指令。

本地主动招呼提供单独可编辑文案，不在后台请求模型匹配人格，因此自定义人格可能需要用户同步调整本地文案。这样保留了已选择的低费用、低常驻开销和无声行为。
