# 团团 0.3.0：养成、本地招呼与索引记忆

日期：2026-11-15。版本 0.3.0（build 6）。本机可运行包，不是已公证的分发版，也不是真实 OpenRouter 账号已经调通的证明。

## 开始使用

打开同目录的 `TuanTuan-0.3.0.app`，或解压 `TuanTuan-0.3.0.zip` 后双击。需要 Apple Silicon 和 macOS 15+。这是本机 ad-hoc 签名，未做 Developer ID 公证。

菜单栏爪印或宠物右键可以聊天、显示或隐藏、暂停招呼、打开设置和退出。设置在同时载入养成和记忆后多一页「养成」。聊天窗口里，已完成并落盘的报告可以用「记为任务事实」提交到待确认或调研范围记忆；私人聊天不会因此写入。

主动发送才会读取钥匙串并访问 OpenRouter，可能产生模型费用；调研还可能产生搜索费用。这次交付没有使用真实 key，也没有发起付费请求。

## 静置三十分钟

测量日：2026-11-15。系统：macOS 15.6（24G84），Apple Silicon，12 个逻辑核心，内存 17,179,869,184 字节。外部 Python 读取 `ps` 的用户态加内核态累计时间，以及进程树 RSS。观察器不计入应用进程。CPU 以单个核心满载为 100%。RSS 的 `ps` 数值按 1024 字节换算成字节。100 MB 预算按 100,000,000 字节。

应用以 `--observe-idle-at` 启动。这个参数只把 `companion.json` 和记忆目录放到测量用的临时目录，不打开聊天或设置，也不读取生产钥匙串。桌面不是隔离基准；采样不剔除用户活动。同机已经有一个 0.2.0 `--chat` 进程，测量期间没有关闭它，它的 CPU 和 RSS 不在下表内。

| 指标 | 静置 | 随后的原生校验 |
| --- | ---: | ---: |
| 观察时长 | 1800.126 秒 | 9.689 秒 |
| 采样 | 357 次，约每 5 秒 | 31 次，约每 0.25 秒 |
| CPU 时间差平均 | 0.0050% | 6.8442% |
| CPU 区间峰值 | 0.9872% | 62.3345% |
| 累计 CPU 时间 | 0.09 秒 | 0.64 秒 |
| RSS 峰值 | 53,444,608 字节 | 118,276,096 字节 |
| 结束时 RSS | 40,992,768 字节 | 112,033,792 字节 |
| 最大应用进程数 | 1 | 1 |

静置平均 CPU 低于 1%，RSS 峰值低于 100,000,000 字节。356 个区间里没有一个达到 1%；有 4 个区间不低于 0.1%，最高的一个是 0.9872%。约 916 秒时本地招呼写了一次临时 `companion.json`：`greetingsToday` 为 1，亲密度、抚摸计分和聊天计分都是 0。没有创建记忆目录。用户 `~/Library/Application Support/TuanTuan` 在测量前后的文件清单一致，当时只有一个空的 `Tasks` 目录。

原生校验那一列包含分区动画和设置窗口。它的 RSS 峰值高于 100,000,000 字节。设计稿不把活动期套进静置预算，也不承诺工作期仍在 100 MB 内。拖动、真实流式聊天和真实调研没有单独采样。

同一静置窗口里，WindowServer 累计 CPU 388.68 秒，RSS 从 80,412,672 字节降到 75,792,384 字节。这是整个系统的合成器，不能归因给团团。没有运行 `powermetrics`，没有 GPU 或电池数据。

## 同一构建上的其他检查

离线 XCTest 117 项、0 失败，scratch 在 `.work/ai-030`。build 6 的 `--validate-agent-at` 28 项全部通过，包括真实落盘的合成报告、窗口内的「记为任务事实」，以及工作请求不携带私人聊天和人格。报告内容是夹具，不是联网研究结果。

`--validate-at` 共 96 项，其中 9 项为假，总结果因此为假。失败的都是设置窗口快捷键：窗口没有成为 `keyWindow`，Command-V / Command-A 没有作用于字段。快捷键实现这次没有改，不能把这次启动说成键盘路径已重新验收。注入养成和记忆后的「养成」页、未注入时的三页，以及 21 项动画时序，这些检查为真。

## 仍未验收

真实 OpenRouter 账号、所选模型的工具兼容性、拖动手感、真实流式聊天和真实调研的资源峰值、物理多屏、全屏空间、跨应用鼠标，以及 GPU/能耗。旧版五分钟或三十分钟数字不能代替上表。

## 文件

`TuanTuan-0.3.0.zip` 是应用包。`TuanTuan-Source-0.3.0.zip` 含可构建源码、素材、测试、工程和设计文档，以及本说明。它不含 `.work`、用户设置、任务报告、钥匙串、API key 或构建缓存。解压后按 `README.md` 运行 `./build-phase1.sh`。该脚本会把新构建写到工程的 `outputs/phase1/TuanTuan.app`，并覆盖同目录的 `TuanTuan-Phase1.zip`；那个文件名现在装的是本次 0.3.0 构建，不再是 0.1.1 原型包。
