# 团团 0.1.1：分区触摸原型交付

日期：2026-11-14。第一阶段原生 macOS 原型，不是已接入 AI 的完整产品。

## 开始体验

在本机打开同目录的 `TuanTuan.app`；`TuanTuan-Phase1.zip` 为应用压缩包，解压后双击即可。需要 Apple Silicon 和 macOS 15+；这是本机 ad-hoc 签名版本，未做 Developer ID 公证，不作为公开分发包。

单击角色不同部位，拖动移动；右键或菜单栏爪印管理。找不到时点击“回到主屏右下角”。菜单“试试分区反馈”也可分别演示四种动作。尺寸可以调整到 100–220 pt，隐藏保留进程，退出结束进程。

| 点按部位 | 动画反馈 | 本地短句 |
| --- | --- | --- |
| 头顶、耳朵上方区域 | 头部局部点头、轻弹 | 嗯，头顶这里好舒服。 |
| 脸颊、脸部中段 | 头部轻蹭、脸红 | 蹭蹭你的手。 |
| 肚子、下方身躯 | 身躯软弹，轻微带动头部 | 软软的肚子，轻轻摸。 |
| 右侧尾巴 | 尾巴局部摆动，头身不一起摇 | 尾巴摇一摇。 |

没有声音；动作最长约 0.9 秒，结束回到静置，不维持持续呼吸或摆尾循环。连续点按替换旧动作而不是叠加；拖动不计抚摸，透明像素不触发。隐藏和休眠清理动作与反馈气泡。

## 为什么仍然轻量

继续用同一张原创透明 PNG，头、身、尾三个局部图层共享位图，以 Core Animation 做短动作。不是四种全图缩放，也没有常驻动画帧循环、Live2D 或外部渲染进程。素材在运行时是 512 × 512，而非原始大图。

这是图片分层原型，不是完整骨骼、网格变形或逐帧重绘动画。接缝通过局部重叠和小幅动作处理；不能承诺大角度动作无接缝。热区依据原图 alpha 和相对坐标，尚未随动画变形逐帧更新命中。后续可在用户认可角色和手感后升级独立姿态或更精细的部位素材。

## 实测：必须区分两版

本机 macOS 15.6、单个在线显示器，外部 Python/ps 观察应用及其子进程。CPU 以单个核心满载为 100%；内存使用 RSS，MB 为十进制 1,000,000 字节。

| 指标 | 0.1.0 静态基线 | 0.1.1 分区互动最终构建复测 |
| --- | ---: | ---: |
| 观察时长 | 1800.05 秒 | 300.114 秒 |
| 采样数 | 309 | 56 |
| CPU 时间差平均 | 0.2872% | 0.1966% |
| CPU 采样峰值 | 2.0836% | 4.1020% |
| RSS 峰值 | 19.218 MB | 34.537 MB |
| 最大应用进程数 | 1 | 1 |

静态基线通过三十分钟初始预算检查；分区版最终构建的五分钟复测未超平均 CPU 1% 和 RSS 100 MB 目标，但**不能因此宣称新版完成三十分钟验收**。表内新版数据来自动画清理修复后的最终构建；更早的候选版初测不作为本表结果。真实桌面并非隔离基准环境；采样不会自动剔除用户活动，没有对动作峰值进行专项高频测量。操作系统可能回收或换出页面，RSS 不等于完整物理内存归因。

观察器不计入应用常驻进程。WindowServer 记录仅是系统背景，无法把其他应用活动排除后归因给团团；没有 GPU、系统能耗或电池测量。不能据此比较两版本谁更省电。

## 当前验证边界

Release 构建、arm64 架构、本机签名与应用压缩包完整性已检查。纯逻辑 XCTest 16 项通过；AppKit 内部检查 33 项通过，包括分区 alpha 命中、反馈启动、气泡保持、停止清理、显示隐藏、缩放与休眠恢复。

时序动画检查 21 项通过，确认四种动作确实在对应局部呈现层发生、结束后恢复静止姿态并清空动画条目、连续点按不堆积、旧清理回调不会打断新触摸。检查中先发现 AppKit 保留已完成动画条目的情况，已增加触摸后一次可取消的清理，不增加静置轮询。临时诊断探针已经移除。

应用内部验证只操作团团自身，不读取用户屏幕或注入其他应用输入。跨应用真实鼠标点击、全屏空间、物理多屏和动作质感仍需要用户体验确认，不能用内部检查冒充端到端验收。

## 未实现的范围

没有联网、OpenRouter、角色 system prompt 编辑、长期记忆、工作 Agent、亲密度计分或主动招呼。反馈文案是本地文本，不是 AI 生成。位置与尺寸尚未持久化，重启恢复默认。后续实现以已确认 MVP 设计为准，不因为新增触摸反馈提前引入所有 AI 功能。

## 源码

`TuanTuan-Source-0.1.1.zip` 提供原生源码、运行素材、测试、工程配置、构建脚本和设计文档。它不包含 `.work` 构建缓存、应用私人运行数据、API key 或第三方运行时依赖。解压后按 `README.md` 运行 `./build-phase1.sh`；纯逻辑用 `swift test`，窗口与动画用应用的 `--validate-at` 入口验证。
